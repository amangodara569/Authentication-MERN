# Authentication-MERN

## Folder structure

- [`client/`](./client/README.md) - Frontend application files.
- [`server/`](./server/README.md) - Backend application files.
- [`server/config/`](./server/config/README.md) - Backend configuration and service connections.
- [`server/controllers/`](./server/controllers/README.md) - Request handlers and application logic.
- [`server/modals/`](./server/modals/README.md) - MongoDB data models and schemas.
- [`server/routes/`](./server/routes/README.md) - API route definitions and route-to-controller connections.
- [`.vscode/`](./.vscode/README.md) - Recommended VS Code extensions for this project.

## Server setup

1. Create `server/.env` from `server/.env.example`.
2. Run `npm install` in `server`.
3. Run `npm start` in `server`.
